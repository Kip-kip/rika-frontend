# rika-frontend — Rika public website

The customer-facing Rika platform (vanilla HTML/CSS/JS, zero build step).
Homepage + tools: visualizer, measurement, quotation, calculator.
Everything runs client-side; no photos ever leave the browser.

- Design system: `shared/css/rika.css` (`--af-*` tokens)
- Pricing single-source: `shared/js/rika-config.js`
- Tools: `tools/{visualizer,measurement,quotation,calculator}/`
- Project brain + roadmap: see `RIKA.md` / `RIKA_ROADMAP.md` (kept on the dev box)
