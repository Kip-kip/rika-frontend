📖 A taste: the three tiers

Most Kenyan homes get the best value from Comfort for the main rooms and Essential for the rest, with Premium where privacy, noise or security matter most. Essential = standard clear glass, basic hardware, 1-year warranty. Comfort = tinted glass, thicker frame, soft-close, 3-year warranty. Premium = dark tint or double-glaze, soft-close + anti-burglar mesh, 10-year warranty.
